A restore is checked, not assumed: the tree is hashed after unpacking and compared with the digest taken at quarantine time. Timestamps are excluded because no filesystem reproduces them; names, contents, links and the executable bit are not.

Findings for a quarantined package stay open. It is one restore away from being back, so a count that dropped here would show this machine clean while the package sits in the archive.
